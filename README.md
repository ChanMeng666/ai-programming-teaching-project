## Try it

Open **[programming.chanmeng.org](https://programming.chanmeng.org/)**. Nothing to install.

The site opens on the current course, TECHNEST 2026. It reads in English and 简体中文.

## Why learn here

- **Five courses, all open.** TECHNEST 2026, Peyvand Academy 2026, HER WAKA 2026, Summer 2025 and Winter 2024 stay online, so you can start from any of them.
- **A tutor that shows its sources.** Ask the chat tutor on any page. It answers from the course content and names the lessons it used.
- **It ends in something real.** The capstone showcase shows the projects the TECHNEST 2026 students built.

```mermaid
flowchart LR
    Q([Your question]) --> W[Chat tutor]
    W --> V[Search the<br/>course lessons]
    V --> M[Write an answer<br/>from what it found]
    M --> A([Answer with<br/>lesson references])
```

## For your agent

This page is all a person needs. Everything else is written for agents: clone the repo and point yours at [`CLAUDE.md`](CLAUDE.md). To run the site locally:

```bash
git clone https://github.com/ChanMeng666/ai-programming-teaching-project
cd ai-programming-teaching-project && npm install && npm start
```
